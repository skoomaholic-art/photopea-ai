# Third-party libraries and services

## Current Poster Markup runtime

- **ag-psd 31.0.2**, MIT: https://github.com/Agamnentzar/ag-psd. Compiled locally to `assets/psd.js`; reads/writes layered PSDs. Includes **base64-js 1.5.1** and **pako 2.1.0**, both MIT. Full notices are distributed in `assets/PSD-LICENSES.txt`, generated by `npm run build:vendor`.
- **IMG.LY background-removal 1.7.0**, AGPL-3.0: https://github.com/imgly/background-removal-js. Dynamically loaded only for local background removal; model downloaded from IMG.LY. Distribution/use must comply with AGPL or a separate IMG.LY license.
- **Puter.js**, official hosted SDK: https://js.puter.com/v2/ and https://docs.puter.com/. Account authentication and optional image generation; provider/account terms and quotas apply.
- **Photopea**, embedded external application: https://www.photopea.com/api/live. No proprietary Photopea code is copied here.
- **TMDB**: official search/artwork API. Approved logo is included unmodified as `assets/tmdb-logo.svg`. Attribution appears in the application. Free developer use is non-commercial; commercial use requires appropriate licensing. TMDB data and poster images are not covered by this repository's software notices.
- **OpenAI / xAI**: optional official server-side image edit APIs. Paid services; no keys distributed in browser code.
