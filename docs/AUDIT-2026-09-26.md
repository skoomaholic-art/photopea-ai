## Внешние блокировки и оставшаяся работа

1. **Обновить опубликованный Worker.** Нужны GitHub repository secrets `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`. В доступном окружении они не заданы; прошлый deploy останавливался именно на проверке секретов. После их добавления запустить `Deploy Cloudflare Worker`, затем проверить `/api/status` и настоящий поиск. Ключи нельзя присылать в чат или вставлять в HTML.
2. **Живая Photopea заблокирована ответом 403.** Это повторно подтверждено на исправленной ветке в run `36203168743`, job `108293956252`. Клиентский код теперь правильно завершает ожидание. Он не может отменить политику внешнего сервиса или гарантировать доступность iframe. Нужно проверить доступ из целевого браузера/сети и, если отказ сохраняется, обратиться к Photopea. Обход через подмену защитных заголовков не используется.
3. **Браузерные проверки новой ветки выполнены в CI.** Мобильные сценарии, переключение редакторов и проверки console errors входят в прошедший обычный набор; настоящая ML проверена отдельно. Локальная установка Chromium остаётся недоступной. После обновления production Worker нужен живой поиск с настроенными ключами и проверка результата на опубликованном сайте.
4. **Провайдеры с ключами.** Настроенность не равна проверенной работе аккаунта. GPT/Grok не проверялись платным вызовом; Carve/Removal выключены по умолчанию. Бесплатный безлимит этих API не подтверждён.
5. **Возврат Photopea имеет границу возможностей.** PNG возвращается в упрощённый редактор, многослойный PSD сохраняется для повторного открытия в Photopea. Произвольные маски, эффекты и smart objects обратно в нативные элементы приложения не разбираются. Это сохранённое ограничение, не полная двусторонняя конвертация.
6. **Качество AI и ML.** Нет гарантии точной казахской надписи от генератора или идеального вырезания сложного логотипа локальной моделью. Исходник остаётся доступным, результат применяется вручную. Текущий визуальный редактор не заменяет ручную маску ретуши.
7. **Хранение.** IndexedDB зависит от браузера и очистки данных. Автосохранение не является облачной резервной копией. Переносимый файл проекта нужно скачивать для хранения вне браузера.
8. **Права и покрытие исходников.** TMDB/Fanart требуют выполнения условий использования; Commons хранит разные лицензии. TVmaze/Commons fallback не найдёт все фильмы, все русские названия или полный комплект textless/логотипов.
