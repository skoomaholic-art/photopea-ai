Локально Playwright обнаруживает 41 сценарий в пяти файлах, включая два внешних opt-in теста. Успех 36 тестов в Codespaces нельзя переносить на эти неопубликованные изменения.

Unit-тесты исполняют код приложения в Happy DOM с настоящим рендерером Canvas, декодируют PNG и PSD и разбирают ZIP. Внешние API и сообщения Photopea имитируются. Проверено:

- Нет прозрачных граничных пикселей на контрольном постере с внешней альфа-рамкой, поворотом и масштабом.

- ТОП10: порядок пяти слоёв, начальная блокировка, фильтры только фона, сохранение, открытие и IndexedDB.

- Карточки превью совпадают с экспортом, выбранный ZIP содержит шесть изображений.
- Стикер заменяется и удаляется, масштаб ограничен первым сегментом; undo/redo и открытие проекта восстанавливают данные.
- Имитированный Photopea round trip возвращает результат во все назначения, сохраняет PSD и открывает его повторно; повторные переключения не меняют постеры.
- Точное название обязательно; кредитная ошибка восстанавливает кнопку; AI-результат не заменяет исходник автоматически.
- Поиск, альтернативные постеры, пустые результаты, квота и сеть через mock; добавление в Паровозик не затрагивает постер.
- Mock удаления фона сохраняет прозрачность и трансформации, ошибка не блокирует повторную попытку.

- В проверенных DOM-сценариях не зарегистрированы runtime-ошибки.

### Конкретные технические ограничения

1. Localhost теперь доступен и серверные тесты пройдены. Браузерная блокировка осталась: executable Chromium отсутствует, `npx playwright install chromium --only-shell` получает `End of central directory record signature not found`. Мобильная компоновка, реальные жесты мыши, шрифты и live-iframe объединённой версии остаются непроверенными здесь.
2. Обнаружен 41 Playwright-сценарий. Их нужно выполнить на той же объединённой версии в Codespaces/CI после `npx playwright install --with-deps chromium`; два реальных внешних сценария включаются отдельно.
3. Настоящие платные Grok/GPT/Puter-запросы не запускались. Адаптеры проверены только по официальным контрактам и mock-ответам; доступность аккаунтов/балансы не подтверждены.
4. Пользовательский скриншот подтверждает успешный запуск реальной IMG.LY-модели в его Codespaces. Здесь проверен mock; качество удаления фона и работу модели на объединённой версии это не подтверждает.
5. PNG из Photopea возвращается как композитный слой; сохранённый PSD используется для повторного открытия. Произвольные Photopea masks/effects не преобразуются в нативные слои упрощённых редакторов. Текст Паровозика передаётся текстовым слоем, стикеры отдельными изображениями.
6. Точное соответствие стикеров утраченным файлам референсов и визуальная читаемость всех надписей в минимальном размере требуют проверки в обычном браузере. Формы, перечисленные надписи, цвета, прозрачность вне плашек и границы реализованы, но визуальная проверка не подменяется численными тестами.
7. Объединённые изменения остаются локальными до отдельного подтверждения на push. Push в `main` запускает настроенные публикации Pages и Worker; для CI-проверки без деплоя нужна отдельная ветка и pull request.
