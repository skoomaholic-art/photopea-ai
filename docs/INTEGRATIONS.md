# Интеграции Poster Markup

Проверка кода: **26 сентября 2026 года**. Тарифы ниже были записаны 24 сентября; условия Carve, Removal.AI, TVmaze, стоимость Grok и отсутствие Free tier GPT Image повторно проверены 26 сентября. Цены могут измениться; платные генерации не выполнялись.

Важное различие: Node-сервер использует прямые ключи OpenAI/xAI. Cloudflare Worker использует OpenRouter для Grok/GPT, отдельный binding Workers AI и опциональные удалённые адаптеры удаления фона. Наличие адаптера не доказывает доступность или наличие денег на опубликованном аккаунте. Puter.js в текущем `index.html` не загружается; строки про Puter ниже описывают прежний вариант, а не активный провайдер.

## Сервисы и ограничения

| Сервис | Что реализовано | Бесплатный доступ и тариф |
| --- | --- | --- |
| xAI Grok Imagine 2.0 | Серверный официальный Images Edit API с PNG-референсом, до 3 вариантов | Бесплатного безлимитного API не подтверждено. Вход: $0.01/изображение. Выход low 1K/1.5K/2K: $0.04/$0.05/$0.06; medium: $0.06/$0.07/$0.08 |
| OpenAI GPT Image 2 | Серверный официальный Images Edit API, PNG, transparent background | Free tier не поддерживается. За 1 млн image-токенов: вход $4, кешированный вход $1, выход $15. Текстовый вход $2.50, кешированный $0.625. Цена картинки зависит от размера и качества |
| Puter | В текущем приложении не подключён | Предыдущие ошибки были связаны с квотой аккаунта; бесплатный безлимит не подтверждён |
| TMDB | Search movie/TV, images одного тайтла, proxy оригинальных изображений | Бесплатно для некоммерческого использования с атрибуцией. Коммерческому проекту требуется лицензия. Защитный лимит около 40 запросов/сек может меняться; HTTP 429 обрабатывается |
| Removal.AI | Адаптер Worker есть, выключен по умолчанию; проверен с fake fetch | Бесплатный режим сайта: 0.25 MP для личного использования. Это не подтверждение бесплатной производственной API-квоты; удалённый API требует ключ и кредиты |
| Carve | Официальный REST API и адаптер Worker есть, выключен по умолчанию; живой запрос не выполнялся | Пробный 1 балл, API доступен. Изображение стоит 1 балл. Разовая покупка 1 балла: 32 ₽; подписка 100 баллов: 499 ₽/месяц. Постоянного бесплатного HD-безлимита нет |
| IMG.LY | Локальное удаление фона `@imgly/background-removal@1.7.0` | Нет оплаты за запрос или API-ключа; AGPL-3.0. Требуются загрузка модели, доступ к CDN, достаточная память и совместимый браузер |
| Photopea | iframe, двусторонний официальный Live Messaging | Встраивание публичного редактора; наличие рекламы/доступность зависят от Photopea. Сервис не хранит ключи Grok/GPT приложения |

Лимиты GPT Image 2: Free не поддерживается; Tier 1: 5 изображений/мин и 100 000 токенов/мин; более высокие tiers имеют другие пределы. Актуальный доступ определяется аккаунтом. Локальный сервер дополнительно ограничивает AI до **5 операций генерации/мин на IP**; одна операция запрашивает до трёх результатов. Это собственный предел приложения, не бесплатная квота сервиса.

API Carve использует `X-API-Key`; официальный маршрут `https://api.carve.photos/api/v1/images/remove_bg`. Для включения уже имеющегося адаптера Worker нужны `CARVE_API_KEY` и `REMOTE_BACKGROUND_ENABLED=true`. Для Removal.AI нужны `REMOVAL_AI_KEY` и тот же флаг. По умолчанию приложение использует локальную модель без оплаты за вызов; во время разработки удалённые платные обработки не вызываются.

TVmaze: официальный API без ключа, CORS, минимум 20 запросов за 10 секунд на IP, возможен HTTP 429. Каталог сериалов, а не всех фильмов; нужен обратный линк на TVmaze. Commons: анонимный официальный MediaWiki API с `origin=*`, лицензия проверяется для каждого изображения. Это ограниченный резервный поиск, не равноценная замена TMDB/Fanart и не бесплатный безлимитный каталог.

AI может ошибаться в кириллице, дизайне и прозрачности. Точный промпт и корректная передача PNG не гарантируют качество модели. Результаты нормализуются в настоящий PNG, сравниваются с исходником и применяются только вручную.

## Переменные окружения

Создайте серверный `.env` по `.env.example`. Существующий `.env` не перезаписывайте. Никакие ключи не вводятся в HTML, клиентский JavaScript, URL или логи.

| Переменная | Значение / назначение |
| --- | --- |
| `TMDB_READ_ACCESS_TOKEN` | Предпочтительный серверный Read Access Token TMDB |
| `TMDB_API_KEY` | Альтернатива токену TMDB; достаточно одного из двух |
| `XAI_API_KEY` | Серверный ключ xAI |
| `OPENAI_API_KEY` | Серверный ключ OpenAI |
| `AI_REQUESTS_ENABLED` | По умолчанию `false`; `true` разрешает платные серверные запросы |
| `XAI_IMAGE_MODEL` | `grok-imagine-image-2.0`; неизвестная модель отклоняется до запроса |
| `OPENAI_IMAGE_MODEL` | `gpt-image-2` или `gpt-image-2-2026-04-21` |
| `API_TIMEOUT_MS` | По умолчанию `90000` |
| `APP_ACCESS_PASSWORD` | Basic Auth на весь сервер. Обязателен при включённом платном AI и запуске на публичном интерфейсе |
| `ALLOWED_ORIGINS` | Точные разрешённые origins через запятую, без `*`. Пусто для одного origin |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE` | Только тесты: путь к установленному Chromium, если не используется штатный Playwright |

При Basic Auth имя пользователя произвольное, пароль берётся из `APP_ACCESS_PASSWORD`. Используйте HTTPS. Для простого рабочего запуска размещайте UI и API на одном origin. Разнесённому UI с защищённым API понадобится собственная схема авторизации/reverse proxy; один `poster-api` не настраивает такую авторизацию.

Worker дополнительно использует `OPENROUTER_API_KEY`, `OPENROUTER_OPENAI_IMAGE_MODEL`, `OPENROUTER_XAI_IMAGE_MODEL`, `CLOUDFLARE_IMAGE_MODEL`, `FANART_API_KEY` и необязательный `FANART_CLIENT_KEY`. Переменные заданы примерами в `.env.example`. `TMDB_READ_ACCESS_TOKEN`, `TMDB_ACCESS_TOKEN` и `TMDB_BEARER_TOKEN` теперь принимаются последовательно сервером и Worker. Health сообщает настроенность, а не проверку ключа внешним запросом.

Для публикации Worker через GitHub Actions требуются repository secrets `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`. Секреты провайдеров задаются отдельно в Cloudflare Worker Secrets. Отсутствие deploy-secrets уже оставило старую версию API на сайте. Без них публикация клиентской части не обновляет Worker. После настройки нужно запустить workflow `Deploy Cloudflare Worker` и проверить `/api/status`.

## Маршруты и диагностика

| Маршрут | Назначение |
| --- | --- |
| `GET /api/config` | Флаги наличия ключей, разрешения AI и имена моделей |
| `GET /api/health` | Работоспособность локального сервера и те же флаги |
| `GET /api/status` | Совместимый alias health с `apiVersion` |
| `GET /api/images/search?q=...&year=...` | Активный общий поиск TMDB/Fanart/Commons/TVmaze |
| `GET /api/images/proxy?url=...` | Загрузка изображений разрешённых источников |
| `GET /api/posters?query=...&year=2026&type=movie` | Название на русском или английском, необязательный год; type movie/tv/multi |
| `GET /api/posters/images?type=movie&id=...` | До 48 постеров выбранного тайтла, большее разрешение сначала |
| `GET /api/tmdb-image?path=/...jpg&size=original` | Только разрешённый TMDB CDN, до 25 МБ |
| `POST /api/ai/generate` | JSON: provider grok/gpt, prompt, inputImage data URL, n 1..3 |

Конфигурация возвращает `upstreamChecked: false`: наличие ключа не доказывает его валидность или наличие денег. Health check не расходует кредиты и не делает запросов к AI.

Ошибки: 400 неверные данные/модель; 401 неверный ключ; 403 запрет/платный режим выключен; 404 неизвестный маршрут/модель; 402 недостаток кредитов; 429 превышение лимита; 500 внутренняя ошибка; 502 ошибочный ответ внешнего сервиса; 503 отсутствие ключа; 504 таймаут. Сырые ошибки провайдера и секреты клиенту не возвращаются. Автоматического повтора платных запросов или переключения на другой платный сервис нет.

Статика раздаётся по разрешённому списку. `.env`, Git, серверные исходники и тесты недоступны через HTTP. Сборка Pages также использует разрешённый список; весь репозиторий в артефакт не попадает.

## Photopea и сохранение слоёв

Первичная передача отправляет в iframe скрипт Live Messaging: документ создаётся в master-размере, затем добавляются отдельные слои. Сохранённый PSD повторно открывается через ArrayBuffer. Проверяются `event.origin` и `event.source`; каждая команда ожидает `done`, а запрос данных также ждёт payload. Таймаут команды 30 секунд блокирует продолжение очереди до явной перезагрузки Photopea, чтобы запоздалый ответ не завершил другую операцию. Первичная готовность iframe ожидается до 20 секунд.

Вход через вкладку, кнопку и повторную загрузку теперь использует один handshake. `load` iframe не означает готовность. При отсутствии `done` возникает понятная ошибка и сохраняются локальные макеты; кнопка перезагрузки создаёт новую очередь. Отказ Photopea HTTP 403 / blocked-by-response нельзя исправить клиентским снятием защиты. Live-проверка требуется отдельно от mock.

Возврат ранее переданной композиции использует `app.activeDocument.saveToOE("psd:true")`, затем `saveToOE("png")`. PNG вставляется в целевой макет, PSD хранится в его проекте и открывается автоматически при повторном редактировании макета в Photopea. Произвольная структура слоёв Photopea остаётся в PSD, а не преобразуется обратно в нативные элементы Poster/Train/TOP10. PNG возвращается через cover при несовпадении соотношений сторон.

Тексты Паровозика создаются отдельными текстовыми слоями, изображения и стикеры размещаются через `app.open(..., null, true)`. Номер ТОП10 передаётся как SVG-ассет. При экспорте PNG Паровозика сначала масштабируется вся master-композиция, затем она разрезается на шесть равных частей.
