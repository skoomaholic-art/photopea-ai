## Где находятся исходные файлы

Полный комплект из 20 PNG, переименованные исходники, `manifest.json` с размером, SHA-256 и именами внутри исходного ZIP, `gallery.html`, `README.md` и архив для скачивания размещены в постоянной ChatGPT Library пользователя:

`/DESIGN/Poster Editor/Movie Parodies/`

ZIP: `Poster_Editor_Movie_Parodies.zip`.

**Ограничение:** текущий ZIP содержит только 20 статичных PNG. В нём нет файлов анимации пустого состояния, исходного кода, текстовой истории Codex или проекта After Effects. Не путать с `docs/cinematic-empty-state-godfather.md`: эта коллекция посвящена десяти пародиям на фильмы, а не готовому видеоролику с персонажем и кошкой.

**Деплой:** PNG хранятся в пользовательской Library. Пока не добавлять их к статической сборке Google Cloud Run (вес ~52 МБ) и не утверждать, что доступны на живом сайте, до явного решения о размещении и необходимом формате витрины.
