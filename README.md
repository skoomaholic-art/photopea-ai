# Poster Markup

Редактор в существующем репозитории `photopea-ai`: постеры, ТОП10, Паровозик и встроенная Photopea. Переключение вкладок не перезагружает страницу.

## Запуск в Codespaces или локально

Нужен Node.js 24 (используется и в CI).

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

В веб-версии Codespaces откройте нижнюю вкладку **Порты**, найдите **4173** и нажмите значок открытия в браузере. На своём компьютере: http://localhost:4173.

Ключи не нужны для редактирования, PNG/ZIP, сохранения проектов или Photopea. Серверные функции настраиваются в `.env` из `.env.example`. Не перезаписывайте существующий `.env`. По умолчанию платные AI-запросы выключены.

## Рабочие пространства

| Раздел | Master-размер | Слои и экспорт |
| --- | --- | --- |
| Вертикальный постер | 800 × 1200 | Постер и логотип, PNG |
| Горизонтальный постер | 1920 × 1080 | Независимые постер и логотип, PNG |
| ТОП10 | 800 × 1400 | Номер, логотип, затемнение, изображение, фон; PNG |
| Паровозик | 2952 × 366 | Несколько изображений, текст, фон, стикер; ZIP |
| Photopea | Размер переданного документа | Многослойный PSD и возврат результата |

### Постеры

У двух форматов отдельные изображения, координаты, масштаб, поворот, порядок, фон, прозрачность, видимость, замки и имена файлов. Зелёный тумблер открывает слой, красный блокирует трансформации.

Постер заполняет холст через **cover/crop** с сохранением пропорций. Смещение и поворот ограничены так, чтобы геометрия изображения закрывала весь формат. Равномерная внешняя альфа-рамка исходного PNG обрезается при загрузке. Искусственная заливка цветом края не используется. Прозрачность логотипа сохраняется; внутренние прозрачные отверстия самого исходника не дорисовываются.

Кнопки скачивают вертикальный PNG, горизонтальный PNG или один ZIP с обоими. Экспорт берётся из состояния нужного формата, а не из видимого CSS-превью. Проект JSON содержит обе композиции; автосохранение использует IndexedDB браузера.

### ТОП10

Master всегда 800 × 1400, независимо от размера превью. Слои сверху вниз: TOP10 Number, Logo, Bottom Darkening, Background Image, Canvas Background. Номер по умолчанию 2, диапазон 1..10. Номер и затемнение сначала заблокированы.

Затемнение создаётся автоматически, не удаляется, остаётся над фоном. Доступны цвет, интенсивность и начало градиента. Фильтры яркости, контраста и насыщенности изменяют только Background Image. Изображения, номер и логотип поддерживают трансформации; PNG, сохранение/открытие JSON и автосохранение независимы от других разделов.

### Паровозик

Один master 2952 × 366, шесть сегментов по 492 × 366. Загрузите широкое изображение или добавьте слои, настройте кадрирование, выберите стикер и проверьте режим «Как на устройстве».

Есть перемещение, масштаб, поворот, кадрирование, порядок/видимость/замки слоёв, текст, локальное удаление фона выбранного изображения, отмена/повтор, сохранение/открытие проекта и автосохранение. Стикер всегда выше остальных слоёв и ограничен первым сегментом.

«Скачать все размеры» создаёт `Паровозик.zip` с четырьмя папками:

- `1 - 164x122`
- `2 - 246x183`
- `3 - 328x244`
- `4 - 492x366`

В каждой ровно шесть PNG: `part_1.png` .. `part_6.png`. «Скачать выбранный размер» создаёт ZIP с одной папкой. Все размеры получаются из одного master: сначала масштабирование полной композиции, затем шесть последовательных срезов. Направляющие, номера, промежутки и скругления превью в PNG не попадают.

### Photopea

Кнопка редактирования текущей композиции в Photopea переключает приложение на внутренний iframe. Через Live Messaging отправляется скрипт создания документа с отдельными слоями, именами, порядком, видимостью, непрозрачностью и блокировками. Изображения размещаются как отдельные смарт-объекты с масштабом, поворотом и координатами. Номер ТОП10 передаётся из SVG-ассета, текст Паровозика создаётся текстовым слоем.

Над iframe есть «В вертикальный», «В горизонтальный», «В Паровозик», «В ТОП10» и «Авто». При возврате переданной композиции приложение получает PNG и сохраняет PSD со слоями. PNG становится изображением в выбранном редакторе. **Произвольные слои, маски и эффекты Photopea не переводятся обратно в набор редактируемых элементов упрощённого редактора.** При повторном редактировании этого макета в Photopea сохранённый PSD открывается автоматически.

### Поиск, AI и удаление фона

- TMDB: русское/английское название, год, превью, оригинальное разрешение. «Другие постеры» показывает изображения одного тайтла. Результат можно отправить в активный постер, ТОП10 или Паровозик.
- Grok / GPT: точное название обязательно, промпт дополняется требованиями сохранения дизайна. Исходник остаётся слева, выбранный результат справа. Он заменяет логотип только по кнопке «Переместить на постер».
- Официальные Grok/GPT API платные. Puter использует лимиты аккаунта пользователя. Нехватка кредитов не оставляет кнопку заблокированной.
- Удаление фона выполняет локальная модель IMG.LY. Первый запуск скачивает модель; результат и качество зависят от изображения и памяти устройства.

## Проверки без платных запросов

```bash
npm ci
npm run build:vendor
npm run check:syntax
npm run smoke
npm run test:unit
npx playwright install --with-deps chromium
npm run test:e2e
npm run build:static
```

Unit-тесты создают и декодируют реальные PNG/ZIP/PSD, проверяют пиксели, состояния и серверные ответы с fake fetch. Они не подменяют браузерный прогон. Playwright по умолчанию использует имитаторы внешних API; тестовый сервер запускается без ключей и с выключенной платной генерацией. Реальные Photopea и локальная ML-модель включаются отдельно через `REAL_PHOTOPEA=1` и `REAL_BACKGROUND=1`.

Если `npm run test:server` сообщает `Missing script`, сначала проверьте `git log -1 --oneline` и `npm run`: в исходной удалённой версии этой команды не было. Она добавлена вместе с `scripts/dev-server.mjs` и `tests/server.test.mjs`. Добавление одной записи в `package.json` не заменяет получение всей доработанной версии. Скриншот успешного прогона другой копии не подтверждает локальные неопубликованные коммиты.

Статус текущей проверки и техническая блокировка Chromium: [docs/AUDIT-2026-09-24.md](docs/AUDIT-2026-09-24.md).

## Файлы

- `index.html`, `poster-app.js`, `poster-app.css`, `poster-overrides.css`: основной редактор.
- `editor-core.js`: геометрия, изображения, IndexedDB, API, переключение.
- `top10-editor.js`, `train-editor.js`, `train-app.css`: активные отдельные редакторы; `top10-app.js` и `train-app.js` сохранены, но HTML их не загружает.
- `photopea-bridge.js`, `assets/psd.js`: Live Messaging и PSD.
- `scripts/dev-server.mjs`: API и безопасная раздача статики.
- Старые файлы Studio сохранены в репозитории, но текущий HTML их не загружает.

## Публикация и доступность

Изменения в рабочем дереве ещё не меняют опубликованный сайт. В этой работе push/deploy не выполнялись.

Статическая сборка `dist/` содержит только разрешённые клиентские файлы. GitHub Pages не исполняет Node API. Для TMDB/Grok/GPT нужен сервер или Cloudflare Worker. Для отдельного API адрес задаётся в `<meta name="poster-api" content="https://api.example.com">`. Локальный dev-server при раздаче HTML заменяет этот адрес на свой origin, чтобы разработка не обращалась к опубликованному Worker.

Codespaces с остановленной средой не является постоянным хостингом. Статический сайт на Pages не зависит от открытого Codespaces, но доступность внешних Photopea/AI/TMDB/CDN гарантировать нельзя.
